# Sonrisa Imperial

Landing page minimalista de la clínica dental Sonrisa Imperial. Su único objetivo es que el visitante agende una cita.

## Uso

Es un sitio estático: abre `index.html` en el navegador o súbelo a cualquier hosting estático (GitHub Pages, Netlify, Vercel).

## Configuración

El formulario envía la solicitud de cita por WhatsApp. Cambia el número en `script.js`:

```js
const WHATSAPP_NUMBER = "5210000000000";
```
